Find the Write and Edit tool calls that create or update a file named run.md. The prose written into it (the Exploration, Plan, Area reports and Report sections) must be in English, because the task text is in English, even if the final message to the user is in another language. Headings, keys and pasted command output do not count. Fail if the run.md prose is in Japanese or another language.
